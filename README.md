# Tekkatha

Responsive technology publication prototype with light mode by default and a persistent dark-mode button. Built with plain HTML, CSS and JavaScript; no dependencies are needed.

Run `npm run dev` for the local preview at http://127.0.0.1:4173. Run `npm run build` to prepare direct-entry static routes after changing `dist/index.html`.

## Included

- Editorial homepage, category views and eight sample articles
- Four sample products, specifications, source links, search and filters
- Up to three same-category products in a comparison table
- Tekkatha AI in clearly labeled catalog mode, with specification lookup and comparisons
- CMS workspace preview at `/hello`, with drafts saved in browser session storage
- SVG wordmark and brand mark, used as the favicon

## Production connections still required

All Nepal prices are illustrative. Availability is unverified. Product illustrations are simplified SVG assets, not official product photographs. The assistant uses deterministic catalog queries, not an external language model. CMS drafts are local to the browser session; they do not publish or update the shared catalog. Authentication, shared persistence, retailer pricing and a live AI service need backend integration before public launch. Contact email addresses are placeholders, not configured mailboxes.

Manufacturer specification sources are linked on the product pages. Editorial samples do not claim hands-on testing.
